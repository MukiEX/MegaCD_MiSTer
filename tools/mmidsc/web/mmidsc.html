LaserActive disc converter

Turns an .mmi disc image into a .dscmmi file that the MiSTer LaserActive core can play. It all happens on this computer: nothing is uploaded.

  1. Choose the disc image

  2. Choose the picture quality

    Higher quality makes a bigger file that the MiSTer has to read faster.

  3. Convert

    You’ll be asked where to save the new file. Keep this tab open until it finishes.

What this does

An .mmi stores the disc’s video losslessly, which is more data per second than a MiSTer can read. This tool compresses the video with VESA Display Stream Compression at a fixed rate, so every frame is the same size, and copies everything else (the CD data, the digital and analog audio) unchanged. Keep your .mmi: the .dscmmi is a playback copy.

Conversion uses every processor core and takes a while: roughly the length of the disc side times one to three, depending on the computer. It needs Chrome, Edge or another browser that can save large files directly; in Firefox and Safari it keeps the file in browser storage first and then hands it to you as a download, which needs twice the free disk space.

This is the same converter as the mmidsc command-line tool, built for the browser; the files it writes are identical.
